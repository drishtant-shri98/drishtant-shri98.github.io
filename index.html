Selected work

One Grid. Very Different Operating Profiles.

A reproducible analysis of Canadian electricity capacity against actual generation, built from Canada Energy Regulator open data. Installed capacity turns out to be a poor proxy for what a fuel type actually contributes, and the gap between the two is the whole story. Written as a fully self-contained document, so the figures rebuild from the raw source every time.

R · R Markdown · Canada Energy Regulator open data

Live

Emotion classification for student reflections

A Python pipeline that scores open-text reflections against the GoEmotions taxonomy, giving program staff a read on cohort sentiment without anyone having to read every entry. Run entirely on local hardware so participant text never leaves the environment.

Python · HuggingFace Transformers · GoEmotions · pandas

Monte Carlo risk model for a reviewer-based business case

A simulation of revenue and cost outcomes across thousands of scenarios, built to replace a single-point projection with a distribution and an explicit downside. Presented to the CEO and CTO as the basis for a go or no-go decision.

Python · Monte Carlo simulation · scenario modelling
